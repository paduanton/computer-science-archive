# Evidências reais

Capturas reais realizadas no navegador em 23/09/2026 (horário de Brasília). Os terminais usam ttyd em um contêiner Linux temporário com Python 3.12.14. Os comandos Python são executados diretamente nesse contêiner; correspondem às chamadas docker compose descritas no README. Os horários dos logs e terminais estão em UTC. As interfaces foram geradas em /tmp/interfaces e comparadas aos módulos incluídos no projeto. O comando cmp terminou sem diferenças. Os testes de métodos selecionaram 28 casos; os casos especiais selecionaram 21, seguidos da suíte completa com 38 aprovados.

Os nove PNGs dos dois laboratórios foram capturados diretamente pelo navegador.
Não houve montagem de resultados nem edição dos pixels das capturas.
A apresentação usa os clientes reais e um terminal web com processos reais.
Os scripts temporários de captura não são necessários para executar os laboratórios.

Consulte ../ROTEIRO_PRINTS.md para repetir as demonstrações manualmente.
